# Unarine Portfolio V1

A zero-dependency, responsive portfolio for immediate deployment.

## Preview locally

Open `index.html` directly in a browser, or run:

```bash
python -m http.server 8000
```

Then visit `http://localhost:8000`.

## Deploy to Vercel

### Fastest method
1. Extract this folder.
2. Push the files to a new GitHub repository.
3. Import that repository into Vercel.
4. Framework preset: `Other`.
5. No build command is required.
6. Output directory: leave blank or use `.`.

### Vercel CLI

```bash
npx vercel
```

## Before sending the portfolio link

1. Replace the note inside the **Freelance Client Website** card with the client's real live URL.
2. Confirm every external link opens correctly.
3. Update any wording that needs to match your exact formal job title or school naming.
4. Do not label unfinished projects as delivered products.

## Why this emergency architecture

- No npm packages or framework build failures.
- No backend, database, API keys or secrets.
- Fast static hosting on Vercel, Netlify, GitHub Pages or Afrihost.
- Semantic HTML, responsive CSS, mobile navigation and basic SEO metadata.
- Easy later migration to React, Astro or Next.js when the portfolio becomes a full content platform.
