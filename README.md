# Unarine Luvhimbi — Portfolio

A small, static portfolio site for selected software, automation, security and client-delivery work.

## Design direction

- Warm, light editorial palette: paper, ink, sage and muted rust.
- Typography uses DM Sans, Manrope and DM Mono.
- Responsive layout with a compact mobile navigation.
- Project cards distinguish shipped client work, active development and research.
- Engineering notes are short, first-person write-ups tied to real projects and lessons.
- No framework or build step. Plain HTML, CSS and JavaScript.

## Structure

- `index.html` — portfolio, selected work, notes, about and contact
- `styles.css` — design system and responsive styling
- `script.js` — mobile navigation and current year
- `articles/` — individual engineering notes

## Run locally

Open `index.html` in a browser, or use any static file server.

## Deployment

The project is configured for static deployment and currently uses Vercel configuration in `vercel.json`.

## Content accuracy

Projects are labelled by status. Research and prototypes are not presented as production systems, and client work is described at the level of delivery currently completed.
